# Atlas Ragnarok — VS Code

> Tech-blue thunder above. Crimson fire below. Pure black through the middle.
> The end-of-days color theme for VS Code, **Cursor**, and **VSCodium**.

![Atlas Ragnarok preview](https://raw.githubusercontent.com/AyoubTadlaoui/atlas-ragnarok/main/screenshots/01-hero-vignette.png)

## Install

**VS Code / Cursor / VSCodium**

1. Open the Extensions sidebar (`⌘⇧X` / `Ctrl+Shift+X`)
2. Search for **Atlas Ragnarok**
3. Click **Install**
4. Open the Command Palette (`⌘⇧P` / `Ctrl+Shift+P`) → **Color Theme** → pick **Atlas Ragnarok**

Or from the command line:

```bash
code --install-extension AyoubTadlaoui.atlas-ragnarok
```

**Open VSX (VSCodium, Gitpod, etc.)**

```bash
# In VSCodium:
codium --install-extension AyoubTadlaoui.atlas-ragnarok
```

## Palette

Built on the syntactic structure of [Vesper](https://github.com/raunofreiberg/vesper) (MIT). The warm-accent family is replaced by a Tailwind blue gradient, and a pure-black background grounds everything.

| Role | Hex |
|------|-----|
| Background | `#000000` |
| Foreground | `#ffffff` |
| Thunder-blue (functions, types, cursor) | `#3b82f6` |
| Thunder-blue deep (tags, numbers) | `#2563eb` |
| Thunder-blue bright (constants, links) | `#60a5fa` |
| Thunder-blue pale (interfaces, decorators) | `#93c5fd` |
| Peppermint (strings, git-added) | `#99ffe4` |
| Gray (keywords, operators) | `#a0a0a0` |
| Crimson (errors, git-deleted) | `#ff8080` |
| Selection | `#1e3a5f` |

## Same theme everywhere

This is the VS Code port of [Atlas Ragnarok](https://github.com/AyoubTadlaoui/atlas-ragnarok) — a Ghostty terminal theme + GLSL shader available across:

- **Editors**: VS Code, Cursor, VSCodium, Zed, JetBrains, Neovim, Vim, Helix, Sublime Text
- **Terminals**: Ghostty (with shader), Alacritty, Kitty, WezTerm, iTerm2, Windows Terminal
