# Changelog

All notable changes to the Atlas Ragnarok VS Code theme will be documented here.
Follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) + [SemVer](https://semver.org/).

## [1.0.0] — 2026-05-18

### Added
- Initial release.
- Workbench colors covering editor, sidebar, activity bar, status bar, tabs, panels, terminal, debugger, and git decorations.
- TextMate token colors for comments, strings, numbers, keywords, functions, types, tags, variables, properties, decorators, and markdown.
- Semantic token colors honoring LSP-driven highlighting where available.
- Bracket-pair colorization across six levels.
- Built on the Vesper structure with the warm-accent family remapped to a Tailwind blue gradient.
