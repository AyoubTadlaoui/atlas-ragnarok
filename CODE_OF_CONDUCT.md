# Code of Conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Short version

Be respectful. Critique ideas, not people. No harassment, no slurs, no
personal attacks. Disagreement is fine; hostility is not.

## Scope

These standards apply to all project spaces: issues, pull requests,
discussions, and any project-related communication that happens in public.

## Enforcement

Issues can be reported to the maintainer at
[atlas.kaisar@icloud.com](mailto:atlas.kaisar@icloud.com).
Reports are handled privately. Consequences range from a private warning to
permanent ban from the project, proportional to severity and repetition.

For the full text, including all guidelines and enforcement details, see the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
